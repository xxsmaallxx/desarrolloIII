# Survey App

Aplicación web básica para registrar encuestas con validación de fecha.

## Tecnologías
- Node.js
- Express
- CORS
- HTML + JavaScript

## Instalación

### Backend

cd backend
npm install
npm start

Servidor corre en:
http://localhost:3000

### Frontend

Abrir el archivo:
frontend/index.html
en el navegador.

## Funcionalidades
- Registro de encuestas
- Validación de fecha DD/MM/AAAA
- Listado dinámico
- Sin almacenamiento de datos sensibles
